# Catalyst Program — Site

Static site for the Catalyst Program, built around an interactive particle-field
background (click/tap anywhere to add particles).

## Structure

- `index.html` — the entire site: particle-field background + content overlay
  (nav, hero, About, Programs, Contact, footer). All copy is **example placeholder
  text** meant to be replaced.

The particle-field background is adapted from Brian Foerster's `particle-field` demo.

## Editing

It's a single self-contained HTML file — no build step. Open `index.html` in a
browser to preview, edit the markup/styles inline, and commit.

## Deployment

Deployed via **GitHub Pages** from the `main` branch root. Pushing to `main`
publishes automatically.
